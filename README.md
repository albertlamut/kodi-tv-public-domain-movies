# Classic Cinema for Kodi — v0.1.4

Author / Autor: Albert Lamut — albertlamut@gmail.com

## English
Classic film catalogue with 114 entries and 39 entries containing external streaming links. Browse A–Z, by year or decade, search titles, save favorites, and explore Oscars, Golden Globes, BAFTA, Cannes and Venice award categories. Some award sections may be empty.

### Installation
1. Download `plugin.video.classiccinema-0.1.4.zip` from Releases (or the `dist` folder).
2. In Kodi, enable Settings > System > Add-ons > Unknown sources if necessary.
3. Open Add-ons > Install from zip file and select the installation ZIP.
4. Open Classic Cinema under Video add-ons.

Requires Kodi with Python 3 add-on support; internet access for streaming. External links may stop working.

## Español
Catálogo de cine clásico con 114 fichas y 39 fichas con enlaces externos de reproducción. Incluye navegación alfabética, por año y década, búsqueda, favoritos y filtros de premios Oscar, Globos de Oro, BAFTA, Cannes y Venecia. Algunas categorías pueden estar vacías.

### Instalación
1. Descarga `plugin.video.classiccinema-0.1.4.zip` desde Releases (o la carpeta `dist`).
2. En Kodi, activa Ajustes > Sistema > Add-ons > Orígenes desconocidos si es necesario.
3. Selecciona Add-ons > Instalar desde un archivo ZIP.
4. Abre Classic Cinema en los complementos de video.

Requiere Kodi con soporte Python 3 e internet para reproducir.
